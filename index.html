关于本站

本站是一个轻量级的应用下载中心，托管于 GitHub Pages，通过 GitHub Releases API 自动同步各应用的最新版本与下载地址，无需手动维护下载链接。

工作原理

  • 每个应用对应一个 GitHub 仓库，发布 Release 时上传安装包（APK / EXE 等）。
  • 本站调用 GitHub 公开 API，自动拉取最新 Release 的资产列表。
  • 页面渲染版本号与下载按钮，新版本发布后自动同步。

主要特性

自动同步版本 多应用切换 下载源切换 本地缓存加速 请求超时重试 响应式适配

使用说明

  • 在「首页」选择应用，点击下载按钮即可获取安装包。
  • 如遇下载缓慢，可切换「加速下载」源。
  • 页面数据缓存 10 分钟，重复访问无需重复请求。

技术信息

构建于 GitHub Pages · 数据源 GitHub Releases API · 纯前端实现，无后端服务器。
